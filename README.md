# FPGA DSP Examples

Verilog implementations of DSP building blocks for Xilinx FPGAs. 
Simulated with Vivado Simulator.

## Included

- **160-tap FIR filter** — 44.1 kHz, low resource usage (used in digital audio equalizer, AADECA 2023)
- **4-level PWM DAC** — high-resolution output DAC topology using only digital pins


## Target

Xilinx Artix-7. Testbench compatible with Vivado Simulator.
